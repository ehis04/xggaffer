Process for creating a prediction model 

1. Data Collection 
Collect data from website and transform to CSV 

2. Data Preparation 
features.py: Define what features the model will learn from 
prepare_data.py: transform CSV into ML-ready train/test sets and create derived features from raw data 

3. Model Training 
train_model.py train scikit-learn model and save 
evaluate.py: measure how good the model is 

4. Making Predictions 
predict.py: load saved model and predict on new data 
views.py: expose predictions via REST API
